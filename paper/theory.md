# Why a tenant's LoRA is expensive for a shared drafter

Notation. The base target defines `p0 = softmax(z0)` at a given context. A
tenant adapter applied at strength `s` perturbs the logits; write the
first-order perturbation as `s*u`, so the adapted target is
`p_s = softmax(z0 + s*u) + O(s^2)`. The shared drafter `q` was trained against
`p0` and achieves base acceptance `beta_0 = sum_v min(p0_v, q_v) = 1 - TVD(p0, q)`.

## 1. Acceptance falls linearly in adapter strength

Expanding the softmax,

    p_s,v = p0,v * (1 + s*(u_v - ubar)) + O(s^2),      ubar = E_{p0}[u]

so

    TVD(p0, p_s) = (s/2) * E_{p0}|u - ubar| + O(s^2)
                 =: (s/2) * kappa .

`kappa` is the **adapter shift coefficient**: the mean absolute deviation of the
adapter's logit perturbation under the base model's own next-token
distribution. By the triangle inequality,

    beta(s) = 1 - TVD(p_s, q) >= beta_0 - (s/2)*kappa ,

with approximate equality whenever the perturbation direction is unrelated to
the drafter's existing error — the generic case, since the drafter was fit
before the tenant existed. **Acceptance degrades linearly in adapter strength,
at a rate set by a single scalar that is measurable from the adapter alone.**

## 2. Throughput falls superlinearly, and the penalty is quadratic in speculation depth

With `gamma` draft tokens per step, expected emitted tokens per step is

    T(beta) = sum_{i=0..gamma} beta^i = (1 - beta^(gamma+1)) / (1 - beta) .

Write `eps = 1 - beta`. Near the high-acceptance regime that good drafters
operate in,

    T = sum_i (1 - eps)^i = (gamma+1) - eps * gamma(gamma+1)/2 + O(eps^2) ,

so `dT/dbeta ≈ gamma(gamma+1)/2`. At `gamma = 4` that is a **10x amplifier**:
a 5-point acceptance drop costs half a token per step. Composing with §1,

    Delta_T  ≈  gamma(gamma+1)/4 * s * kappa .

The cost of ignoring a tenant's adapter grows **quadratically in the
speculation depth**. This is the load-bearing observation for 2026-era serving:
EAGLE-3.1 and block-diffusion drafters like DFlash are pushing `gamma` up
precisely because acceptance got good enough to support it, which makes the
un-adapted-drafter penalty worse, not better, over time.

## 3. The server is also running at the wrong operating point

The optimal block size solves `argmax_gamma T(beta)/(gamma*c + 1)` (sequential
drafter, draft/target cost ratio `c`), and it is monotone in `beta`. A server
that tunes `gamma` once against the base model therefore over-drafts for every
adapted tenant: it pays the full draft cost for tokens whose acceptance
probability has fallen. This is a second-order loss stacked on the first.

## 4. A low-rank correction on the drafter is the right shape of fix

To restore acceptance the drafter must move from `p0` toward `p_s`, i.e. its
logits must acquire the component `s*u`. But `u` was itself generated by a
rank-`r` perturbation of the target's weights, so to first order it lives in a
low-dimensional subspace of logit space. A low-rank perturbation of the drafter
is thus the natural function class for the correction, which is what motivates
companion ranks of 4-8 rather than a full drafter fine-tune. E2's rank sweep
tests where this stops holding.

## 5. On-policy training data is free

Speculative sampling is distribution-preserving: the emitted sequence is
distributed exactly as the target's own output. Therefore **the contexts on
which the drafter is invoked in deployment are distributed as `p_s`** — the
adapted target's output distribution. Sampling rollouts from the adapted target
is already on-policy for the drafter. No drafter rollouts, no interleaved
sampling, no RL machinery: an ordinary teacher-rollout distillation set is
exactly the right training distribution. This is what makes a companion adapter
cheap enough to mint per tenant.

## 6. The loss should be TVD, not KL

Since `beta = 1 - TVD(p, q)`, minimising total variation distance *is*
maximising the expected acceptance rate — the objective and the metric are the
same object. Forward KL, the conventional distillation loss, is only a surrogate
(and by Pinsker's inequality bounds TVD loosely from above). E2 measures how
much that distinction is worth in practice.
